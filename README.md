# Mobile_Inventory
 Repository for mobile inventory development on android.

Реализован спавн предметов из пула в рандомной точке внутри зоны.
Реализовано хватание и перетаскивание предметов.
Реализован стак предметов в сумке и без.
Реализовано располагание предметов в сумке.
Реализованы предметы в сумке как на один слот так и больше.
Реализована сетка сумки, которую можно настраивать по форме и количеству ячеек.
